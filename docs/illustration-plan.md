# 7. AI 일러스트 삽입 계획

## 제작 방식과 승인 순서

- Codex가 `imagegen` 스킬과 기본 내장 이미지 생성 도구를 사용해 직접 제작한다.
- 먼저 예나와 민서의 캐릭터 설정 시트를 생성하고 사용자의 승인을 받는다. 승인 전에는 16개 본 장면을 생성하지 않는다.
- 수정 요청이 있으면 캐릭터 시트를 수정하고 다시 확인받는다. 승인된 시트의 경로와 버전을 기록한다.
- 캐릭터 승인 후 실제 사건 15개와 마지막 편지 장면을 각각 한 이미지로 생성한다. 장면을 합치거나 생략하지 않는다.
- 모든 장면 생성에 승인된 시트를 인물·의상·헤어스타일·그림체 참조 이미지로 전달한다. 텍스트 설명만으로 인물을 재생성하지 않는다.
- 얼굴, 머리, 의상 색과 형태, 신체 비율, 선 굵기와 채색을 장면마다 검수한다. 불일치가 크면 해당 장면만 다시 생성한다. 생성형 이미지 특성상 완벽한 동일성을 보장하지는 않는다.

## 공통 미술 기준

- 파스텔 핑크, 크림 화이트, 연한 베이지 중심의 귀여운 2D 연애 게임 일러스트.
- 동일한 성인 예비부부 두 사람을 유지하며 예나의 실제 감정을 단정하거나 과장된 분노로 표현하지 않는다.
- 캐릭터 시안 v4: 예나는 앞머리 없이 이마가 드러나는 긴 짙은 갈색 머리, 민서는 가는 앞머리가 자연스럽게 내려와 이마가 살짝 비치는 흑발 시스루 댄디컷. 기존보다 기장을 약간 짧게 다듬고 귀 주변과 뒷머리를 정리한다. 민서의 머리를 위로 넘기거나 이마를 완전히 드러내지 않는다.
- 예나 홈웨어는 사용자가 제공한 첫 사진 왼쪽 제품처럼 크림색 바탕에 파란 꽃무늬가 있는 나시 원피스형 잠옷. 프릴 어깨끈·네크라인과 밑단을 유지한다. 민서는 두 번째 사진의 짙은 남색 바탕에 분홍·아이보리·연보라·연파랑 코끼리 무늬가 있는 포근한 긴팔·긴바지 수면잠옷. 둥근 목과 짧은 단추 여밈을 유지한다. 제품 사진은 의상만 참조하고 기존 성인 캐릭터의 얼굴과 헤어스타일은 유지한다.
- 예나 외출복은 오트밀 가디건, 크림 블라우스, 더스티 로즈 바지와 베이지 숄더백. 야근·귀가·출근·회사 장면에서 동일하게 유지한다.
- 집 장면과 회사 장면 사이에는 상황에 맞는 고정 의상을 사용한다. 시안의 세부 외형은 사용자 승인 후 확정한다.
- 같은 침대, 크림색 침구, 따뜻한 집 배경을 반복 사용한다. 밤은 부드러운 저조도, 아침은 따뜻한 자연광으로 표현한다.
- 본 장면은 가로 3:2 구도로 통일하고 모바일에서도 인물과 핵심 행동이 잘 보이게 배치한다.
- 대사, 선택지, 편지 원문은 이미지에 넣지 않고 HTML 텍스트로 표시한다. 휴대폰 화면은 문자를 읽을 수 없는 추상적인 UI로 표현한다.
- scene-05는 얼굴에 손이 닿는 대화 장면이며 시술 도구나 상처를 그리지 않는다.
- scene-14는 사용자가 공유했다고 설명한 메시지 장면이다. 해당 뉴스의 실제 사실 여부를 확정하는 기사 제목이나 인물 초상은 넣지 않는다.
- scene-16은 민서가 편지 봉투를 내미는 모습으로, 예나가 이미 화해했다고 단정하는 장면을 추가하지 않는다.

## 이미지 목록과 연결

`data/story-illustrations.json`을 단일 연결 데이터로 사용한다. `id`를 스토리의 장면 ID와 일치시키고 `src`를 이미지 주소, `alt`를 대체 텍스트로 사용한다.

- scene-01: 밤 11시까지 회사에서 야근하는 예나
- scene-02: 침대에서 깊게 잠든 민서
- scene-03: 자정 가까이 집에 돌아온 예나와 잠깐 인사하는 민서
- scene-04: 씻고 침대에 누운 예나에게 고생했다며 다가가는 민서
- scene-05: 민서의 손이 얼굴에 닿고 필러 시술을 언급하는 예나
- scene-06: 예나를 껴안고 잠든 민서, 팔을 맞댄 채 영상을 보는 예나
- scene-07: 잠깐 깨어 실눈으로 휴대폰을 확인하는 민서
- scene-08: 민서가 깨어 있는지 확인한 뒤 등을 돌려 휴대폰을 보는 예나
- scene-09: 아침에 말을 건 민서와 대답하지 않는 예나
- scene-10: 말없이 먼저 출근하는 예나
- scene-11: 식탁 위 빵을 발견하고 사진을 찍는 민서
- scene-12: 말랑해진 빵을 다시 넣을지 카톡으로 묻는 민서
- scene-13: 빵을 그대로 두고 보낸 주식 관련 개인톡에 답장이 없는 상황
- scene-14: 이후 보낸 뉴스 개인톡이 읽히지 않은 상황
- scene-15: 개인톡과 달리 단체 채팅방에서 대화하는 예나

## 저장과 구현 지침

- 캐릭터 시안: `public/images/characters/character-sheet-v4.png`.
- 현재 본 장면 파일: `assets/1.png`부터 `assets/15.png`까지. `public/images/scene-16.png`는 미제공 상태다.
- 생성 원본은 내장 도구 저장 위치에서 프로젝트로 복사한다. 프로젝트 밖 파일 경로를 웹사이트에서 참조하지 않는다.
- 사건 15개는 사용자가 제공한 assets/1.png부터 assets/15.png까지 번호대로 연결했다. scene-16 편지용 이미지는 아직 제공되지 않았다.
- HTML·CSS·JavaScript 게임을 구현했다. 실제 사건 15개, 지금의 마음 질문, 마지막 편지까지 플레이할 수 있다.
- 게임은 연결 데이터를 읽어 장면 ID에 해당하는 이미지를 자동 렌더링한다. 편지 화면은 scene-16을 사용한다. 현재 사건 화면은 제공된 이미지만 원본 비율로 표시하고, 날짜·시간 외의 이모지와 장소 문구는 표시하지 않는다.
- 이미지 로드 실패 시 대체 UI를 표시하고 이미지 비율을 예약해 레이아웃을 유지한다.
- 첫 장면 이후 이미지는 지연 로딩하고 다음 장면만 미리 불러온다. 모바일에서는 인물이나 핵심 행동이 잘리지 않도록 표시한다.
- 장면별 최종 프롬프트와 사용한 참조 이미지 버전을 기록한다.

## 비용

- 우선 API 키가 필요 없는 기본 내장 이미지 생성 도구를 사용한다. 현재 외부 유료 API 호출이나 추가 결제는 실행하지 않았다.
- 계정별 이미지 생성 한도나 결제 상태는 이 작업 도구로 확인할 수 없다. 무료 또는 무제한이라고 보장하지 않는다.
- 별도 API 비용이나 추가 결제가 필요한 경우 실행 전에 사용자에게 알리고 동의를 받는다. API/CLI 방식으로 자동 전환하지 않는다.
